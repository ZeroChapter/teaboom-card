# Карточка товара — Чайный Бум

Прототип карточки товара для интернет-магазина [Чайный Бум](https://teaboom.ru/).
Тут можно [Посмотреть деплой](https://teaboom-card-pi.vercel.app/).

На странице показан товар «Ананасовый улун»: фото, фасовка, цена, описание и блоки магазина. Это статическая вёрстка без сборки и сервера — HTML, CSS.

## Как открыть

1. Склонируйте репозиторий или скачайте архив.
2. Откройте файл `index.html` в браузере (двойной клик или перетаскивание в окно браузера).

Отдельный сервер и установка зависимостей не нужны. Картинки и логотип подгружаются с сайта магазина, поэтому для полного вида страницы нужен интернет.

## Комментарий по истории

Проект добавлен одним коммитом: он небольшой и не нуждается в декомпозиции на отдельные изменения.
